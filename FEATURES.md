# Kestrel / Hetfit — complete feature pack

Unzip at repo root. Paths are already `app/...`.

Keep your existing `app/src/main/assets/web/vendor/` if not in this zip.
Keep mipmap densities from your repo if needed.

## Features in this build
1. Moonlight theme + frost + motion animations
2. Decluttered Run + Settings
3. Plan progress bars (overall + workout/study/nutrition)
4. Live run + heat map route
5. Lock-screen run notification (distance, time, pace, HR)
6. App shortcuts + Quick Settings tile + splash
7. WorkManager band reconcile
8. Custom Kestrel coach notifications (plan remaining, health tips)
9. Health Connect / Gadgetbridge import bridge
10. Widgets (glass + dashboard, band tv_action)
11. Share sheet Moonlight redesign
12. Monochrome mood faces

## Build
./gradlew assembleDebug

Allow notifications for Kestrel after install.
